# OrdaX Intelligence — repositório histórico arquivado

**Código canônico e SSOT:** [ordaxsystems/ordax-os / system/intelligence](https://github.com/ordaxsystems/ordax-os/tree/main/system/intelligence) (ordax-os/main).

A implementação ativa do OrdaX Intelligence, incluindo Aura, inferência local,
roteamento, streaming, testes e ferramentas de empacotamento, foi consolidada
no monorepo do OS. A partir do cutover, não existem fontes, builds,
pipelines ou serviços ativos mantidos neste repositório histórico.

**Não desenvolver, compilar, publicar ou instalar a partir deste repositório.**
Para qualquer alteração, utilizar exclusivamente a SSOT do OS acima.

O histórico completo de commits, as branches anteriores e as tags permanecem
consultáveis para auditoria. A prova do engine Windows existente foi
[redistribuída no OS sem recompilar](https://github.com/ordaxsystems/ordax-os/releases/tag/windows-local-ai-engine-70fc057-43309006398),
preservando hash e proveniência original. O release histórico nesta origem
permanece disponível somente para rastreabilidade.

ordax-runtime (MCP) e ordax-platform (sessões e autorizações) continuam
independentes do monorepo.
